# AeroAtlas — Atualizações Android

Este repositório contém os APKs, o manifesto de versões e a infraestrutura de publicação das atualizações. O código-fonte do jogo permanece privado e não é armazenado aqui.

- [Versão mais recente](https://github.com/Lotuzzzz/aeroatlas-updates/releases/latest)
- [Manifesto de atualizações](https://github.com/Lotuzzzz/aeroatlas-updates/releases/latest/download/latest.json)

O app confere tamanho, SHA-256, pacote, versão e assinatura antes de abrir a confirmação de instalação do Android. Instale sobre a versão existente para preservar sua partida.
